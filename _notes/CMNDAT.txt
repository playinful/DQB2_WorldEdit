Header

0xC4_b1 = PlayerSex (0: Female, 1: Male)

0xC8 = byte CurrentIsland
0xC9 = byte PreviousIsland (if different than CurrentIsland, play ship animation on load)

0xCD..?? = string PlayerName

0xED = byte Buildertopia Type
0xEE = byte Buildertopia Beta Type
0xEF = byte Buildertopia Gamma Type

0x010D..0x2A40C = Thumbnail (320x180 pixels, 3 bytes per pixel, 172800 total)
0x2A40D = FILETIME Timestamp
0x2A415..0x2A41C = Steam account lock
